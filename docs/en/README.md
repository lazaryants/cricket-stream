## Documentation Rules

- English is the primary project language.
- Russian documentation is maintained in parallel.
- User-visible behavior changes must update both languages.
- Commands must be reviewed against current production paths and service names.
- Production secrets, stream keys, database passwords, deploy keys, and TLS private keys must never appear in documentation.
