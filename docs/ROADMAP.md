# Дорожная карта

## Реализовано

- FastAPI backend, React frontend и PostgreSQL;
- роли Viewer, Operator и Admin;
- создание, редактирование, запуск и остановка трансляций;
- Streamlink и yt-dlp с выбором движка;
- FFmpeg copy без перекодирования;
- одновременный RTMP и защищённый HLS-preview;
- Dashboard, подробная страница и монитор 1/4/9/16;
- live-метрики, диагностика, сессии и логи;
- библиотеки источников и назначений;
- supervisor и повторный запуск;
- проверка версий компонентов;
- Nginx, systemd и HTTPS.

## Ближайшие задачи

1. Автоматические backend-тесты для API, ролей и видеокоманд.
2. Frontend-тесты основных операторских сценариев.
3. GitHub Actions для lint, TypeScript build, Python compile и Alembic check.
4. Устранение оставшихся предупреждений React lint.
5. Оптимизация размера frontend bundle и lazy loading страниц.
6. Более подробная классификация ошибок провайдеров в интерфейсе.

## Следующий этап

- управление несколькими рабочими нодами из одного интерфейса;
- контроль ресурсов нод и распределение потоков;
- уведомления о длительных ошибках источника;
- статистика доступности и история качества потоков;
- резервная нода и регламент переключения;
- экспорт диагностического отчёта без секретных URL.

## Долгосрочно

- полноценная отказоустойчивая схема из двух production-нод;
- централизованные метрики и алертинг;
- плановое обновление видеокомпонентов с проверкой совместимости;
- аудит действий операторов и администраторов.

Загрузчик видеороликов в область проекта не входит.
