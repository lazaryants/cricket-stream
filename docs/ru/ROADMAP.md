# План развития

[English version](../en/ROADMAP.md)

Документ описывает направления развития и не является обязательным календарём релизов.

## Реализовано в 1.0

### Основа

- FastAPI backend;
- PostgreSQL;
- SQLAlchemy и Alembic;
- React и Material UI;
- Nginx, HTTPS и systemd.

### Видеотракт

- Streamlink и yt-dlp;
- Auto и ручной выбор движка;
- FFmpeg stream copy;
- RTMP-выход;
- защищённый HLS-preview;
- desired active;
- retry/backoff;
- сессии, журналы, метрики и диагностика.

### Интерфейс

- Dashboard;
- Monitor 1/4/9/16;
- All Streams;
- Libraries;
- Details и Edit;
- Users и Account;
- Components;
- полный EN/RU интерфейс.

### Безопасность

- Viewer, Operator, Administrator;
- удаление URL из ответов Viewer;
- HLS-токены;
- права в backend.

## Ближайшие приоритеты

### Надёжность

- дополнительный watchdog;
- понятное отображение лимита перезапусков;
- health checks узлов и назначений;
- операционные уведомления;
- тесты длительной работы.

### Планировщик

- запуск и остановка по времени;
- запуск при появлении live-источника;
- шаблоны событий;
- корректная работа с часовыми поясами.

### Аналитика

- исторический uptime;
- количество рестартов;
- средний и максимальный битрейт;
- трафик;
- причины остановок;
- отчёты по мероприятиям.

## Распределённая платформа

Модель узлов существует, полная оркестрация планируется.

- heartbeat;
- сведения о capacity;
- remote worker agents;
- размещение потоков;
- ручной выбор узла;
- failover;
- централизованные журналы и метрики;
- резервные европейские узлы.

## Интеграции

- публичный REST API;
- API tokens или service accounts;
- интеграция с системой мероприятий;
- webhooks;
- внешняя система мониторинга;
- уведомления.

## Медиа-функции

Возможные будущие задачи:

- запись;
- DVR retention;
- создание клипов;
- проверка совместимости кодеков;
- управляемые профили transcoding;
- SRT и другие протоколы.

Они не должны ухудшать основной low-latency stream-copy тракт.

## Пользователи и администрирование

- создание пользователей в браузере;
- изменение ролей;
- отключение и удаление;
- управление сессиями;
- audit log;
- управление узлами;
- системные настройки.

## Документация

- скриншоты EN/RU;
- API reference;
- тренировки disaster recovery;
- автоматическая проверка Markdown-ссылок;
- версии документации для релизов.

## Не является ближайшей целью

- универсальный video downloader;
- замена production switcher;
- неограниченный архив по умолчанию;
- автоматическое перекодирование всех потоков;
- публичный preview без авторизации.
