# ADR 0004: Защищённый HLS-preview

- Статус: принято
- Дата: 2026-08-03

## Контекст

Preview нужен оператору, но публичный HLS обходит авторизацию.

## Решение

Хранить HLS локально и выдавать через авторизованный API с короткоживущими токенами. Не создавать публичный Nginx alias.

## Последствия

Плюсы:

- учёт ролей;
- нет открытого каталога;
- токены истекают;
- preview остаётся частью приложения.

Компромиссы:

- backend участвует в выдаче;
- нужны тесты token/cache;
- access log не должен раскрывать URL.
