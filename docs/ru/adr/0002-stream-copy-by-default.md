# ADR 0002: Stream copy по умолчанию

- Статус: принято
- Дата: 2026-08-03

## Контекст

Основная задача — live relay. Перекодирование увеличивает задержку и CPU.

## Решение

Использовать:

```text
-c:v copy
-c:a copy
```

## Последствия

Плюсы:

- низкий CPU;
- малая задержка;
- больше потоков;
- исходное качество.

Компромиссы:

- нужны совместимые кодеки;
- неподдерживаемый кодек не исправляется;
- bitrate/GOP не нормализуются без transcoding.
