# ADR 0005: Роли Viewer, Operator, Administrator

- Статус: принято
- Дата: 2026-08-03

## Контекст

URL могут раскрывать непубличный источник или адрес публикации.

## Решение

- Viewer: безопасный мониторинг без URL;
- Operator: видит URL, start/stop, source edit, без destination edit;
- Administrator: полный доступ.

Права проверяются backend.

## Последствия

Плюсы:

- least privilege;
- защита маршрута;
- понятное разделение.

Компромиссы:

- ответы зависят от роли;
- каждый endpoint требует проверки;
- скрытия кнопок недостаточно.
