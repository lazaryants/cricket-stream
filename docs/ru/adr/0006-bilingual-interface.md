# ADR 0006: Двуязычный интерфейс, основной английский

- Статус: принято
- Дата: 2026-08-03

## Контекст

Системой пользуются русскоязычные операторы и международные партнёры.

## Решение

Полный EN/RU интерфейс. Английский основной. Выбор сохраняется и меняется без reload.

Документация ведётся на двух языках.

## Последствия

Плюсы:

- международное использование;
- единый опыт;
- документация соответствует UI.

Компромиссы:

- каждое изменение переводится дважды;
- нельзя hard-code строки;
- оба языка требуют layout-теста.
