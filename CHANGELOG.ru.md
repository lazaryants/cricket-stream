# История изменений

В этом документе фиксируются все значимые изменения Cricket Stream Platform.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а версии проекта планируется вести по принципам [Semantic Versioning](https://semver.org/lang/ru/).

[English version](CHANGELOG.md)

## [Не выпущено]

### Планируется

- Запуск трансляций по расписанию
- Распределённые узлы
- Историческая аналитика
- Механизмы высокой доступности
- Уведомления
- Публичный API

## [1.0.0] — 2026-08-03

### Добавлено

#### Управление трансляциями

- Создание, редактирование, запуск, остановка и удаление трансляций
- Желаемое активное состояние и контролируемое восстановление
- Ручной выбор движка источника
- Streamlink как основной движок и yt-dlp как альтернатива
- Runtime-статус, сведения о процессах, сессии и журналы

#### Dashboard и мониторинг

- Dashboard с независимой настройкой видимости карточек
- Полный список трансляций с поиском и фильтрами
- Монитор трансляций с сетками 1/4/9/16
- Защищённый HLS-предпросмотр
- Runtime-обновления через WebSocket

#### Метрики и диагностика

- Разрешение, FPS, битрейт, скорость обработки, кодеки, uptime и dropped frames
- Стабильные коды диагностики и переводы на русском и английском
- Диагностика доступности источника и ошибок процессов
- История сессий и просмотр журналов

#### Библиотеки

- Библиотека повторно используемых источников
- Библиотека RTMP-назначений
- Поиск, фильтрация, создание, редактирование и удаление
- Миграция домена назначений на `rtmp.cricket-stream.icu`

#### Пользователи и безопасность

- Роли Viewer, Operator и Administrator
- Авторизация и управление сессиями
- Смена собственного пароля
- Сброс пароля другого пользователя администратором
- Исключение конфиденциальных URL из API-ответов Viewer
- Короткоживущие токены защищённого HLS-воспроизведения

#### Компоненты

- Отображение установленных версий
- Проверка доступности обновлений
- Локализованные статусы и время проверки

#### Интернационализация

- Полностью двуязычный интерфейс
- Переключение языка без перезапуска
- Сохранение выбранного языка
- Локализованные даты, длительности, метрики, диагностика, формы и ошибки

#### Инфраструктура

- Backend на FastAPI
- PostgreSQL
- SQLAlchemy и Alembic
- Frontend на React 19 и Material UI
- Nginx и HTTPS
- systemd-сервис backend
- Production-развёртывание на `de.cricket-stream.icu`

### Изменено

- FFmpeg переведён на копирование видео и аудио
- RTMP и HLS-preview объединены в одном процессе FFmpeg
- Улучшена таблица трансляций для desktop без горизонтальной прокрутки
- Улучшено повторное подключение плеера во время создания первого HLS-плейлиста
- Синхронизированы конфигурации systemd в репозитории и production
- Домен RTMP-назначений изменён с `video.curling76.ru` на `rtmp.cricket-stream.icu`

### Исправлено

- Согласована уникальность UUID сохранённых назначений в SQLAlchemy и PostgreSQL
- Обновление preview после смены движка
- Сообщения об ошибке запуска недоступного источника
- Восстановление желаемого состояния после перезапуска backend
- Синхронизация REST- и WebSocket-состояния
- Единообразие preview и диагностики на Dashboard, Monitor, в списках, мобильных карточках и подробностях
- Локализованное отображение времени работы свыше 24 часов

### Безопасность

- Viewer не получает URL источников и назначений
- Operator видит оба URL, но не может изменять RTMP-назначения
- Administrator имеет полный доступ
- HLS-файлы не публикуются через открытый Nginx `alias`
- Preview выдаётся через авторизованный API
